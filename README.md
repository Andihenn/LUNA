LUNA
Make your Windows desktop your own.
LUNA is a Windows desktop customization app that brings wallpapers, docks, widgets, visual themes, and app integrations together in one place. Personalize the look of your desktop and add a more unified style to the apps you use every day.
Features
·	Animated wallpapers — Choose from included video backgrounds or set your own wallpaper.
·	Custom desktop dock — Adjust the dock's layout, size, icons, colors, opacity, animations, and auto-hide behavior. It also includes search and system shortcuts.
·	Desktop customization — Personalize desktop icons, taskbar behavior, clock appearance, and other visual details.
·	Widgets — Add clock, media, and music-lyrics widgets to your desktop.
·	Discord and Opera themes — Apply LUNA styling to Discord and customize Opera with a matching look and animated backgrounds.
·	Spotify integration — Customize the Spotify desktop app with the LUNA theme, with an option to restore the original setup.
·	Dedicated YouTube app — Open YouTube in its own app-style window with LUNA styling.
·	Storage cleanup — Scan and clean supported temporary and cache files to help free up disk space.
·	Restore options — Restore supported app and desktop settings when needed.
Download
Download LUNA.zip from the GitHub Releases section, extract the archive, and run LUNA.exe.
